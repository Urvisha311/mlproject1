# KNN Iris Classification

This project demonstrates Iris flower classification using the
K-Nearest Neighbors (KNN) machine learning algorithm in Python.

## Dataset

The Iris dataset contains measurements of iris flowers:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The flowers are classified into three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Algorithm

K-Nearest Neighbors (KNN)

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Steps

1. Load the Iris dataset
2. Explore and visualize the data
3. Split the dataset into training and testing sets
4. Train the KNN classifier
5. Make predictions
6. Evaluate model accuracy
7. Visualize the classification results
